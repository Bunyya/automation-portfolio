# Данные и границы безопасности

Пример запускается локально и не открывает сетевые соединения. В `examples/data/messages.json` используются вымышленные сообщения и адресаты. `SimulatedSink` не содержит учётных данных и не подключается к сервисам.

SQLite хранит ID сообщения, хеш его текста и аудитории, категорию, получателя, статус и число попыток. Исходный текст сообщения в базу не записывается. CLI выводит подготовленный текст в JSON, поэтому для ввода следует использовать только синтетические данные.

Локальные базы SQLite, `.env`, кэш Python и типовые каталоги сборки исключены через `.gitignore`. Исключение файла из Git не заменяет проверку содержимого перед публикацией.
